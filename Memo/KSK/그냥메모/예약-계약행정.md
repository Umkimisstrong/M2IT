하나로의료재단 예약관리팀 계약행정 김해빛나 주임입니다.

계약행정팀 현업에서 사용하는 주요 업무 화면(신전산) 파일 송부드립니다.

업무 진행 순서 및 중요도 순서가 아닌 주요 업무 화면을 일괄 첨부하였으며,

각 화면 내 세부 기능들도 모두 포함하여 확인해주시면 감사하겠습니다.

단, 계약행정팀에서 사용하는 모든 화면이 포함된 건 아니며,

계약 등록 및 선등록 시 사용하는 주요 화면 위주로 첨부한 점 참고부탁드립니다.



▶계약등록
 ● 기초정보 -> **검진계약등록(거래처계약등록)**
 ● 검진예약 -> 홈페이지 예약관리 -> ¹)**계약복사(검진계약복사)**
 ● 기초정보 -> 기초정보출력 -> **검진 계약 출력(검진계약 정보 출력)**
 Ⅹ 검진예약 -> 홈페이지 예약관리 -> ²)**선택검사 설정(선택등록 검사조회설정)** VHMGRRV054S

▶선등록 및 문자 발송

 ● 검진예약 -> **예약선등록**
 ● 검진예약 -> **차트기타일괄조정**
 ▲ 발송관리 -> **그룹발송(그룹문자발송)**
 ▲ 발송관리 -> **발송 확인 및 취소**

▶홈페이지 & 앱 예약 동기화
 Ⅹ 검진예약 -> 홈페이지 예약관리 -> 계약정보 동기화(홈페이지 계약정보 동기화) VHMGRRV055S
 Ⅹ 검진예약 -> 홈페이지 예약관리 -> 일별 CAPA 관리 -- 센터일정관리 VHMGRRV056S
 ● 검진예약 -> 홈페이지 예약관리 -> 예약정보 연동(홈페이지 예약정보 연동)

▶거래처 및 명단 조회

 ● 검진예약 -> **거래처발생현황**
 ● 검진예약 -> **예약접수명부(예약접수 명부 조회)**
 ● 검진예약 -> **예약검증 Data추출(예약검증용 Data 추출)**
